## 代码

```rust
/// 计算字数（中文按字计，西文按词计）
fn count_words(text: &str) -> usize {
    text.split_whitespace()
        .filter(|w| !w.is_empty())
        .count()
}
```

```python
def reading_time(words: int, wpm: int = 220) -> float:
    return round(words / wpm, 1)
```

## 长段落测试

Markdown 的魅力在于它足够简单，同时也足够表达。用纯文本记录想法，随时间的推移积累成体系，
再通过链接把零散的想法编织成网络——这正是本地知识库的价值所在。EasyMD 希望在这件事上做到足够轻、足够快，
让记录和回看都毫不费力。
