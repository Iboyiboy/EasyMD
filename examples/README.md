# EasyMD 示例仓库

这是一个用来体验 EasyMD 的示例文档仓库。你可以直接把它当作知识库模板，也可以换成自己的 Markdown 目录。

## 从这里开始

1. 左侧目录树里 **单击文件夹** 可展开/折叠，**单击文件** 即可在右侧阅读。
2. 右上角悬浮按钮可以切换 **阅读 / 编辑 / 分栏** 三种模式，设置会被记住并对所有文件生效。
3. `Ctrl+O` 打开自己的文档仓库，下次启动会自动回到这里。

## 功能速览

- 目录树：新建 / 重命名 / 删除 / 拖拽移动 / 文件名搜索 / 按名称或修改时间排序
- 阅读：标题锚点跳转、本地文档互链、图片预览、每篇文档独立的阅读位置记忆
- 编辑：常用 Markdown 格式一键插入，支持实时分栏预览，自动保存
- 外观：8 套内置主题、自定义背景色与背景图片、字体与字号、行距、阅读栏宽

详细语法示例见 [格式示例](格式示例.md)，长文排版效果见 [长文阅读测试](笔记/长文阅读.md)。

> 提示：Markdown 里的相对链接可以直接点击，例如上面的两个链接都能在 EasyMD 内打开。

## 常用快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+O` | 打开文档仓库 |
| `Ctrl+S` | 保存当前文档 |
| `Ctrl+N` / `Ctrl+Shift+N` | 新建文件 / 新建文件夹 |
| `F2` | 重命名选中项 |
| `Delete` | 删除选中项（需确认） |
| `Ctrl+F` | 搜索文件名 |
| `Ctrl+B` | 显示 / 隐藏侧栏 |
| `Ctrl+E` / `Ctrl+R` / `Ctrl+P` | 编辑 / 阅读 / 分栏预览 |
| `Ctrl+D` | 切换深色浅色 |
| `F11` | 禅模式（专注阅读） |
